# 项目集合

统一服务器托管多个项目。

## 快速启动

```bash
# 方式1: 双击 start.bat
# 方式2: 命令行运行
python server.py
```

## 项目列表

| 路径 | 项目 | 说明 |
|------|------|------|
| `/` | 作品集 | 个人作品集网站 |
| `/ddz/` | 斗地主 | 在线斗地主游戏 |
| `/hand-particles/` | 手势粒子 | 手势识别粒子特效 |

## 访问地址

- 作品集: http://127.0.0.1:8080/
- 斗地主: http://127.0.0.1:8080/ddz/
- 手势粒子: http://127.0.0.1:8080/hand-particles/

## 技术栈

- **作品集**: HTML, CSS, JavaScript
- **斗地主**: Python, Flask, Flask-SocketIO, SQLite
- **手势粒子**: JavaScript, Canvas, MediaPipe
